# Caudales de la Sociedad del Canal de Maipo

**Decisión para la demo del 21 de noviembre de 2026.** Presentar los caudales como fuente futura de contexto para la central. El visor público confirma que la Sociedad publica información de sus canales. En las páginas consultadas no se pudo verificar una descarga documentada con estación, coordenadas, hora de medición y cobertura para el sector MUT, ni un registro público de desbordes en ese sector.

| Fuente consultada | Qué permite verificar |
|---|---|
| [Telemetría de caudales de la Sociedad](https://www.scmaipo.cl/canalistas/telemetria-de-caudales/) | La Sociedad describe la instrumentación y las curvas de aforo para estimar caudal. Es una descripción del método en HTML. |
| [Boletín oficial, febrero de 2025](https://www.scmaipo.cl/canalistas/wp-content/uploads/2025/02/Gota-a-Gota_No18_Interactivo.pdf) y [visor de caudales](https://www.scmaipo.cl/canalistas/newCaudales/) | El boletín describe la consulta como «en tiempo real». El sitio enlaza una aplicación web embebida. La documentación consultada no cuantifica el desfase entre medición y publicación. |
| [Junta de Vigilancia, caudal del Maipo](https://jvriomaipo.cl/caudal-del-maipo/) | Otra entidad publica una tabla que incluye la bocatoma San Carlos (SCM). La Junta indica que los valores están sujetos a revisión. Una medición de captación no permite localizar un desborde en una calle. |

**Línea para el pitch.** «La Sociedad del Canal de Maipo ya mide caudales. Si conseguimos series con ubicación y hora para esta zona, la central podrá consultarlas en el mapa antes de una tormenta».

Para activar la capa, verificar la correspondencia de cada estación con el tramo, las unidades, la fecha de medición y el permiso de reutilización. El caudal aporta contexto a escala de canal; la prioridad de limpieza se calcula con las señales de la rejilla.
