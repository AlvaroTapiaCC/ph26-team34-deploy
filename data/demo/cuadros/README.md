# Cuadros guardados para la demo

## Decisión sobre cámaras de la UOCT

El 21 de noviembre de 2026 se revisaron las fuentes públicas de la UOCT. El procedimiento publicado regula la entrega de grabaciones a organismos requirentes. Las comunicaciones del MTT describen integraciones de cámaras mediante convenios. En las páginas consultadas quedó sin confirmar tanto un endpoint documentado de imagen como el permiso para capturar periódicamente, almacenar y enviar cuadros a un servicio de clasificación. Para la demo se usan los cuadros de abajo o el celular fijo del equipo. [Procedimiento de entrega de la UOCT](https://www.transporteinforma.cl/centro-de-ayuda/preguntas-frecuentes/como-se-pueden-obtener-las-grabaciones/), [Resolución Exenta 1323/2021](https://www.transporteinforma.cl/content/uploads/2021/06/Rex-Modi-Rex-1657-de-2020_Ok-Digi-12.04_firmado_JDC.pdf), [Convenios anunciados por el MTT](https://www.transporteinforma.cl/noticias/camaras-de-monitoreo-del-mtt-llegan-a-dos-mil-gracias-a-la-colaboracion-publico-privada/)

Para retomar una integración con la UOCT, confirmar por escrito las cámaras cubiertas, el endpoint, la frecuencia permitida y las condiciones de almacenamiento, clasificación y exhibición.
